由 AI搜索观察站长贝果开发。输入官网和最多三个问题，查看回答、品牌提及、官网引用与可获得的来源信息。

安装到 Codex

git clone https://github.com/caicai998/aissgc-geo-visibility.git
mkdir -p ~/.codex/skills
cp -R aissgc-geo-visibility/aissgc-geo-visibility ~/.codex/skills/

刷新技能列表后，输入 $aissgc-geo-visibility 并选择模式。其他 Agent 的技能目录以各自文档为准。

选择使用方式

当前 Agent 模式：Codex 可使用已登录的 CLI 启动独立会话；默认关闭联网，可选择开启实时搜索。其他 Agent 需要提供独立模型调用工具。费用取决于宿主。

豆包 / DeepSeek API 模式：配置自己的 API Key，在本地网页中分别查看结果；API 调用可能收费。

不同通道分别统计，失败不计为未提及。来源标题仅在工具返回时显示，单次检测只是特定问题下的快照。
